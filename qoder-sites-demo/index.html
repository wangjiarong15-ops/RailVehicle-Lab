把转向架的三维结构与运行数据证据放在同一块屏幕上。

RailVehicle-Lab 面向轨道车辆转向架的工程教学与运行数据分析。在线版在浏览器本地解析运行 CSV，把超阈值异常定位到原始数据行号，并用三维教学回放解释相关结构——全程无需 Python、账号或 API 密钥。

默认示例为虚构教学数据 · 非实测 本地计算 · 无云端上传

三步开始体验

  1. 1
    载入示例或你的 CSV示例为明确标记的虚构教学数据；导入仅在浏览器本地解析。
  2. 2
    点击一项异常事件时间轴与曲线游标自动定位到起始样本，并显示原始 CSV 行号。
  3. 3
    观察三维教学回放与证据相关结构高亮、预设教学动画同步；证据面板给出规则与工程局限。

证据与诚实性口径

A原始测量数据：在线版为明确标记的虚构演示值，或用户本地导入（不上传）。
B登记配置转换：在线版无传感器台账，未做增益/偏置/坐标转换。
C三维示意运动：预设教学动画随事件同步，非加速度积分重建的实车运动。

统计异常仅表示 |a| 超过用户设定阈值，不构成零件损坏、运行安全或法规结论。

项目说明

RailVehicle-Lab：可溯源的转向架工程教学与分析平台

同一套工程模型契约与异常判定规则，驱动浏览器在线参赛版与本地 Python/Streamlit 工程完整版。在线版把"数据 → 证据 → 三维解释"的闭环搬到评委无需安装任何环境即可操作的公网页面。

它解决什么问题

传统运行数据分析里，曲线上的一个尖峰很难回答"对应哪一行原始数据、关联哪个结构、是否足以构成结论"。RailVehicle-Lab 把异常事件锚定到原始 CSV 行号与 UTC 时间戳，给出判定规则、峰值观测表与相关结构示意，并明确声明证据不足以支撑诊断结论。

教学侧则用真实 GLB 装配模型展示零部件、传感器测点方向与工况示意动画，帮助理解转向架机械结构，而非用虚构几何冒充工程模型。

技术架构（在线版）

  • core.js加载自包含 GLB 与 viewer-data 契约，重建 layer/holder/spin/link 装配 rig。
  • interactions.js射线拾取零件、高亮/隔离/透明、传感器测点与方向箭头投影。
  • analysis.jsCSV 校验、统计、阈值事件、回放状态机与场景判定（与原 Python 规则同口径）。
  • charts.jsCanvas 三通道曲线、超阈值点、事件带、游标与拖拽寻址。
  • workspace.js数据源/统计/事件/证据面板与统一时间轴，驱动曲线与三维同步。
  • viewer-dock.js视图与渲染控制坞：光照/显示/相机/质量实时调节、恢复默认与 PNG 导出。
  • app.js工作区导航、相机/视角、单一渲染循环与移动端抽屉。

纯前端 ES Modules + 本地 vendored Three.js r180，无后端、无 CDN、无新增运行时依赖。

真实限制与后续路线

  • 三维运动为预设教学示意（类别 C），未做加速度积分重建；缺乏积分初始条件与校准数据。
  • 在线版无传感器登记台账，未做增益/偏置/坐标转换。
  • 统计异常不等于故障诊断；不构成运行安全或法规结论。
  • 路线：登记台账接入、校准流程在线化、更多批次对比与报告导出（先在本地完整版验证）。
