# Evolution III 虚拟试验台

基线为 `97341ce2`。原 10 自由度垂向与点头模型及 2 自由度横移与侧滚模型保留自己的入口。新增整车模型以对称悬挂为假设，在原垂向矩阵上增加车体、前转向架及后转向架各自的横移、侧滚、摇头，共 19 个自由度。构型参考公开铁路车辆的两级悬挂布置，所有数值均为显式教学参数。参考资料只用于检查受力路径和部件相对位置。 [车辆–轨道线性化模型](https://onlinelibrary.wiley.com/doi/10.1155/2019/2015465) · [印度铁路 Siemens EMU 维护手册征求意见稿](https://rdso.indianrailways.gov.in/works/uploads/File/Maintenance%20Manual%20AC%20DC%20EMU%20%28Siemens%29%20-%20Draft%20for%20comments%20from%20Railways%281%29.pdf)

## 方程与坐标

X 向前，Y 向右，Z 向上。正侧滚使 +Y 侧升高，正点头使 +X 侧升高，正摇头使 +X 端偏向 +Y。以静平衡为零初值。垂向坐标与 Phase 9 相同，新增每刚体三个坐标 `[y, φ, ψ]`。转向架中心在车体 X 坐标 `x_i = ±a`，两轴相对转向架在 `x_j = ±b`。

```text
二系横向变形 = yc + xi·ψc + hc·φc − yi + hb·φi
一系横向变形 = yi + xj·ψi + hp·φi − y轨,j
二系侧滚差   = φc − φi
二系摇头差   = ψc − ψi
```

`hc` 是车体质心到二系连接面的下向距离，`hb` 是转向架质心到同连接面的上向距离，`hp` 是转向架质心到一系横向作用点的下向距离。左右垂向弹簧在对称线性化时消去垂向与侧滚交叉项。每台转向架的一系侧滚刚度为 `2 k1z B1²`。每台转向架的二系侧滚刚度为 `k2z B2² + k_ar`。阻尼作同类处理，`B1`、`B2` 为对应左右悬挂半距。每个变形行 `d` 贡献 `k dᵀd` 和 `c dᵀd`，轨面输入形成 `F(t)`，求解 `M q̈ + C q̇ + K q = F(t)`。质量单位 kg，转动惯量 kg·m²，平移刚度 N/m，转动刚度 N·m/rad。轮对横向采用规定输入，轮轨横向蠕滑、蛇行临界速度、轨距变化及脱轨机制均超出模型范围。

四轴均按 `r_j(t)=r(vt−s_j)` 取同一空间轨面上的输入。横向由位移和速度共同激励，垂向经原模型的线性轮轨接触刚度激励。模型尚无左右轮不同高程、车体弹性、间隙和饱和接触，不能用于安全、承载或实车结构验收。

## 求解与数值复核

Newmark 平均加速度法采用 β = 1/4、γ = 1/2。常规积分步长 1 ms，试验复算 0.5 ms，输出均为 200 Hz。当采用局部余弦脉冲时，默认轮距 2.60 m、转向架中心距 17.00 m 和速度 20 m/s 给出四轴输入时延 0、0.130、0.850 和 0.980 s。模态以无阻尼广义特征问题计算，阻尼比为各模态投影。横向频响用各轴速度相关时延在频域施加相位差，位移 RMS 比取车体与首轴输入的同窗 RMS。

默认凸起工况截取 2 s，以 SciPy DOP853 独立积分并将结果对齐至 200 Hz。线位移最大绝对差在 1 ms 和 0.5 ms 步长时分别为 3.190×10⁻⁷ m 与 7.945×10⁻⁸ m，角位移分别为 9.942×10⁻⁸ rad 与 2.485×10⁻⁸ rad。复算的方程残差最大分量绝对值为 5.82×10⁻¹¹，各分量按 N 或 N·m 计量。激励离开末轴后，自由衰减中输出采样点的机械能从 5.599 J 降至 1.786 J。默认矩阵通过对称性、质量及刚度正定性、阻尼半正定性检查，衰减极点实部为负。测试另覆盖零输入、静态横向平移、已知空间轨迹、随机种子与轴间时延。DOP853 对照用于验证积分过程，两个求解器使用同一物理方程。

## 从工况到可复算报告

1. 打开「动力学仿真」，在「计算工况」中选「整车虚拟试验台（19 自由度）」。设置右侧的速度、轨道输入和参数，点击「计算整车响应」。
2. 点击曲线或拖动下方时间轴进行定位。使用倍速、逐帧与峰值定位观察整车，或切换前、后转向架，用原 54 部件 GLB 检查悬挂和安装点。车体透视、整车与局部切换使用相同的计算样本。视窗显示动画倍率，计算值仍按模型单位显示。仿真中的钢轨是几何参照。
3. 在「保存或载入工况」下载 JSON 保存车辆参数。要加载自定义空间轨迹，下载同栏示例并修改 `profile`。每行是 `[距离 m, 横向幅值比例, 垂向幅值比例]`，以零起点、零边界和严格递增的距离构成。支持零输入、正弦、有种子随机谐波与局部平滑脉冲。
4. 「参数扫描与复算」支持速度、二系横向刚度倍数和二系横向阻尼倍数三个轴，各填 1 至 3 个值。先算全网格，再用半步长复算初筛通过的工况。按完整时窗的车体横向加速度 RMS 选择网格内最小方案。筛选侧滚峰值、二系横向行程及线性接触假设。零横向输入或尾轴未完整受激的候选不会参与推荐。周期工况要求尾轴经历一个幅值渐入和一个完整空间周期。灵敏度汇总是保持另外两轴相同、对当前轴首末值计算的有限差分。
5. 下载工况、响应 CSV、试验证据 JSON 或一页 PDF。选择「保存到试验历史」会在本机 SQLite 登记工况、证据摘要、候选摘要和求解配置。打开「历史试验」可以从配置重新求解，由当前输出重新生成摘要。公开模式允许下载，归档仅供本机版使用。历史试验新增独立的 `coupled_trial_history` 表。
6. 点击「将当前工况交给 Copilot」，输入「比较不同二系刚度和阻尼，刚度倍数 0.7、1、1.3，阻尼倍数 0.7、1、1.3，侧滚不超过 5 mrad，行程不超过 20 mm，并生成试验报告」。离线工具实际计算并复核，自动定位候选横向加速度峰值，可把同一复算配置带回试验台。重新打开归档对话只载入上下文，需由用户指令触发复算。

默认 20 m/s、6 s 工况使用 3×3 刚度与阻尼网格、5 mrad 侧滚及 20 mm 二系横向行程上限。基准和网格优选方案的复算 RMS 为 0.0108137 与 0.00826517 m/s²，优选采用基准刚度和阻尼的 0.7 倍，峰值位于 0.220 s。这些约束和结果只适用于本教学算例。扩大到 18、20、22 m/s 的 27 个工况后，优选 RMS 为 0.00799903 m/s²。改变分析时长、空间输入或可行域都可能改变最优候选。

## 三维资源与工程边界

使用 Blender 4.5.3 LTS 无界面重导原模型。校验读取 54 部件、58 个网格和 47,948 个三角形，文件大小 1,457,452 字节，与原 GLB SHA-256 一致。现有部分的装配、稳定 ID 和局部交互继续使用原 GLB。新整车总览复用轮距、轮径和安装横向跨度，增加双架和四轴、车体透视与抗侧滚连杆示意。悬挂连接端分别跟随构架、车体或轮对，程序化连杆可伸缩，局部 GLB 使用已定义的安装点。

模型验证覆盖本机虚构工况。整车外观、转向架简化抗侧滚件以及动态间隙采用示意结构，仍需实际图纸、安装尺寸、匹配的传感器布置和台架/实车数据复核。下一轮可先验证一组可重复的位移、力和加速度基准，再根据真实输入逐步扩展非对称悬挂、轮轨接触及机械干涉分析。

## 浏览器与构建验证方式

- 上一阶段基线重新运行后，725 项 pytest 和 324 个子测试通过，Edge 在 1366×768 与 1920×1080 下通过上一阶段专项。
- 使用 `python -m pytest -q` 运行 Python 回归。本阶段 731 项 pytest 和 324 个子测试通过，失败 0。安装 `signal` 可选依赖后，DOP853 对照也会执行。当前开发环境包含该依赖。
- 使用 `python scripts/run_browser_checks.py --suite evolution-iii` 复测新工作流。Windows 可将 `RAIL_BROWSER_PATH` 指向本机 Edge 可执行文件。专项验证包含整车/GLB 切换、透视、剖切装配、计算样本定位、播放暂停、SQLite 历史复算、Copilot 两项离线工具调用和 PDF 下载。输出默认保存在 `tmp/browser-qa`，启动器为每次验收创建虚构数据的隔离库。
- 1366×768 深色和 1920×1080 浅色中，整车姿态静止在计算峰值附近时均测得 106 次绘制调用和 4,744 个三角形。该统计来自本机 Edge 的软件 WebGL。并行执行回归时，6 秒工况的 9 项和 27 项计算及复算分别耗时约 4.3 秒和 14.3 秒。这些读数用于复现实验环境，尚无独立设备、实际显卡或用户并发负载测试。
- 用 Blender 重导后的模型执行 `python scripts/validate_bogie_glb.py 路径`，并用 `node scripts/check_phase8_contract.mjs` 复核双版本原装配及 CSV 边界。新整车场景仅在 Python 完整版中启用，Qoder RC1 使用原版 GLB。
- Edge 回归支持脚本路径与 Python 模块两种启动方式。模拟 Copilot 服务只绑定回环地址，用于测试限流、重试、流式证据和取消。没有使用真实模型 API。PDF 按 27 个候选导出并实际渲染复核。
