# 整车垂向与点头试验

模型 `rail.vehicle-vertical.v1` 使用教学参数。两台转向架和车体视作刚体，四组轮对视作集中质量。轨面是预先规定的空间曲线，轮轨采用静平衡附近的线性刚度。模型坐标 +Z 向上，正点头使 +X 端抬高。输出分别使用 m、rad、m/s、rad/s、m/s²、rad/s²。质量用 kg，点头转动惯量用 kg·m²。悬挂刚度与阻尼分别用 N/m 和 N·s/m。轴距沿用 GLB 装配契约。质量、惯量、悬挂与轮轨参数采用显式的教学假设，保存工况含全部参数。

## 运动方程

```text
q = [zc, θc, zf, θf, zr, θr, zw1, zw2, zw3, zw4]
M = diag(mc, Ic, mb, Ib, mb, Ib, mw, mw, mw, mw)
e2f = zc + a·θc − zf
e2r = zc − a·θc − zr
e1 = [zf + b·θf − zw1, zf − b·θf − zw2,
      zr + b·θr − zw3, zr − b·θr − zw4]
C = c1·D1ᵀD1 + c2·D2ᵀD2
K = k1·D1ᵀD1 + k2·D2ᵀD2 + kt·WᵀW
M q̈ + C q̇ + K q = kt·Wᵀ r(t)
```

`D1`、`D2` 将刚体广义坐标映射至上述一系和二系相对位移。`W` 选取四组轮对。`a` 是前后转向架中心距的一半，`b` 是转向架轴距的一半。以首轴轨面入口为原点，四轴的输入为 `rᵢ(t) = h(vt − xᵢ)`，其中 `x = [0, 2b, 2a, 2a+2b]`。因此同一轨面下变速同时改变时频和各轴延迟。正弦、多频与有种子随机谱在首个波长内渐入。局部凸起使用有限长度余弦脉冲。随机谱的四项相位可复现，频带与相位组合用于教学。

## 数值与装配

- 采用平均加速度 Newmark `β = 1/4, γ = 1/2`，默认积分步长 1 ms，输出 200 Hz。关于静平衡求解，初位移和速度均为零。输出包括无阻尼固有频率、质量归一化模态、模态投影阻尼比和含耦合阻尼的系统极点。±5% 局部敏感性每次只改变一项参数，报告按参数相对变化归一的响应斜率。
- 测试检查质量与刚度正定、阻尼半正定、整体静态平移、四轴时延、零输入、模态正交和失去外激励后的耗散。使用 SciPy DOP853 比较局部凸起下全部十个自由度，并验证减半步长的收敛趋势。
- 仿真观看前或后单台转向架。GLB 的 B 端为首轴，A 端为末轴。轮对各自升沉并按给定速度旋转，一系连接按构架和轴箱端点更新。固定部件 IDs、原始枢轴、传感器安装契约沿用 RC1 规范。曲线与三维视窗共用采样位置，数值读数按原计算量显示。视窗用同一倍率作用于各位移和点头，必要时统一降低显示倍率以限制主要垂向运动。车体与二系响应提供数值曲线及测点读数。
- 线性轮轨载荷在输出样本处低于零时提示持续接触假设超限。模型范围是无侧滚、无横向运动的线性车辆系统。轮轨分离、撞击、非线性悬挂、左右轮差异及实车或安全认证尚待独立研究。

## 使用与复现

在「动力学仿真」选择「整车垂向与点头（10 自由度）」。填写轨面、速度和悬挂参数后计算。可下载工况 JSON 并重新载入，或设置当前工况为对照基准后改变一个参数。证据 JSON 含模型标识、配置摘要、广义坐标、采样率和逐点响应。Copilot 离线示例为「比较整车凸起仿真 30 m/s，二系刚度降低 20%」，工具返回可复算的教学对照参数和证据编号。

整车验证接受 `model_time_s,reference_axis_m_s2` 两列表头。在采集软件中先完成来源授权、传感器标定、+Z 转换、单位和同一 time-zero 配对，再提交到车体中心或对应构架中心通道。表中时间为仿真相对秒数，必须落在 0.005 s 输出网格，至少三个唯一配对点。报告保留物理 CSV 行号、时间校准说明、结果和原始参考摘要，以及 RMSE、MAE、峰值误差和 Pearson 相关。公开数据来源可声明并保留其来源与授权记录。独立实测仍待验证。
