# RailVehicle-Lab · Qoder 竞赛交付材料

本目录为「RailVehicle-Lab 第四阶段：产品级体验优化、工程验收与竞赛交付」的参赛材料草稿。
全部内容仅基于**已实际完成并经真实浏览器验收**的功能，不含虚构奖项、实车部署、客户案例或认证。

- 在线参赛版（公网，无需 Python / 账号 / API 密钥）：<https://railvehicle-bogie-d1j7uxpvtu6.qoder.zone/>
- 本地完整版：仓库根目录 `streamlit run app.py`（Python / Streamlit / 本地数据库，原则上只读）
- 在线版源码：`qoder-sites-demo/`（纯前端 ES Modules + 本地 vendored Three.js r180，无后端、无 CDN）

## 正式提交前必做

1. **核对官方当前参赛规则**：本环境网络受限，未能抓取官方最新提交要求（见 07「未验证项」）。
   提交前请以官方公告为准，核对材料格式、字数、视频时长与截图规格，并据此调整本目录草稿。
2. 复核公网链接可访问、版本为最新（`get_publish_status` / 资源哈希）。
3. 按 05 的分镜录制 3 分钟演示视频，按 06 清单补齐指定分辨率截图。
4. 确认不提交密钥、数据库、临时产物（`tmp/`、`*.zip`、`*-Staged/`、`.qoder.site` 描述符均不入库）。
