# 05 · 三分钟演示与视频分镜

## 评委可操作的 3 分钟路径（无需 Python / 账号 / API 密钥 / 数据准备）

打开 <https://railvehicle-bogie-d1j7uxpvtu6.qoder.zone/>，点击首页 **「开始三分钟演示」**。
导览条出现在工具栏下方（正常文档流，不遮挡控件），共 7 步，每步驱动**真实**工作区操作：

| # | 步骤 | 真实动作 | 评委看到 | 建议时长 |
| --- | --- | --- | --- | --- |
| 1 | 了解系统定位 | 停留首页 | 定位标语、三入口、虚构/本地徽标、能力边界 | 20s |
| 2 | 体验示例数据 | `loadDemo(0)` + 切到运行分析 | 载入虚构批次 1（120 行），琥珀「虚构演示·非实测」 | 25s |
| 3 | 查看运行曲线 | 切到运行分析 | 三通道共轴曲线、红点超阈值、±阈值虚线、事件带 | 25s |
| 4 | 点击一项异常事件 | 真实 `.event-item.click()` | 事件列表：时长/峰值/原始行号范围 | 25s |
| 5 | 自动定位时间与原始样本 | seek 同步 | 时间轴+曲线游标对齐，读数「CSV 第 32 行」 | 25s |
| 6 | 观察三维教学回放 | 真实 `#tl-play.click()` | 三维构架/轮对预设教学运动 + 相关结构高亮 | 30s |
| 7 | 查看证据与工程局限 | 暂停 + 展开 `#sec-detail` | 判定规则/观测表/行号/相关结构 + 非诊断声明 | 30s |

合计约 180s。导览提供 **上一步 / 下一步 / 重置演示 / 退出导览**；末步「完成演示」后可「重新体验」。
**重置**会真实重载示例数据并回到第 3 步；**退出**隐藏导览条自由探索。导入自己的 CSV 也能复现同一闭环。

### 手动兜底（不依赖导览）

若某步自动动作未生效，评委可手动：首页「体验示例数据」→ 运行分析 → 点事件列表任一项 →
拖时间轴/曲线 → 点「播放」→ 展开右侧「证据 / 部件详情」。所有入口均为真实控件，无硬编码跳过。

## 录制注意

- 录屏前刷新页面确保首页落地；用导览「重置演示」保证每次起点一致。
- 旁白避免「实车精度」「故障诊断」「已部署铁路」等表述（见 07 边界）。
- 若官方要求不同时长/分辨率，以官方规则为准调整分镜（见 README 必做项）。
