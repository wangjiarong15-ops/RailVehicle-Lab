# 07 · 工程局限与路线图

## 真实工程局限（明确声明，不夸大）

1. **统计异常 ≠ 故障诊断**：超阈值仅为统计判定（`|a| > 阈值`，分轴），不构成故障诊断、
   运行安全或法规结论。证据面板与导览末步均明确声明。
2. **三维运动为教学示意（类别 C）**：预设工况动画按事件类别驱动，**不是**由加速度积分重建的
   实车运动，未宣称实车工程精度。
3. **默认示例为虚构教学数据**：带琥珀「虚构演示 · 非实测」徽标；与真实导入数据严格区分。
4. **在线版无登记配置转换 / 传感器台账**：未做幅值/偏置/坐标转换，无车辆整备台账；
   `vehicle_id` 仅要求非空。这些能力仅在本地完整版。
5. **无后端 / 无持久化**：纯静态前端，刷新后回到首页；导入数据仅存于当前会话内存，不上传。
6. **阈值与口径固定移植**：默认阈值 1 m/s²（可调），判定口径与原 Python 一致；未引入新的工程判据。
7. **CSV schema 约束**：必需字段 timestamp/speed_kmh/lateral_accel/vertical_accel 等，
   非法输入拒载并给字段级错误，不做猜测性修复。

## 未验证项（诚实记录）

- **官方当前参赛规则**：本环境网络受限（Web 搜索代理/IP 耗尽），未能抓取官方最新提交要求。
  本目录按用户给定的提交内容清单组织；**正式提交前须以官方公告核对格式/时长/截图规格**。
- **低端移动设备三维性能**：已在 390×844 视口验收无溢出/可操作，但未在真实低端真机测帧率。
- **真实工程数据精度**：在线版未用真实实测数据做工程精度验证（也不宣称）；基线对齐仅针对判定口径。
- **无障碍完整审计**：已做焦点可见、对比度、reduced-motion、键盘可达；未做完整 WCAG 第三方审计。
- **应用内隐藏浏览器**：截图/渲染受限，故验收改用 headless Chrome CDP 真实渲染（见 06），
  不将 DOM 检查等同渲染验收。

## 明确不做的事

- 不输出故障诊断 / 实车精度 / 法规结论；不虚构奖项、实车部署、客户、认证。
- 不上传用户 CSV / 密钥 / 数据库；不强制推送 / 不改主分支；原 Python 工程只读。
- 不为跑分引入新框架；不做未经必要性论证的大规模重构；不删除既有功能。

## 路线图（后续，非本次交付）

1. 传感器登记/标定转换移植（幅值/偏置/坐标），对齐本地完整版 B 类能力。
2. 真实实测数据验证 harness（脱敏后），建立工程精度对照（仍不宣称诊断）。
3. 更多工况场景与可配置教学动画参数；三维 LOD/实例化以改善低端真机帧率。
4. 保存视图 / 导出证据报告（PDF/CSV）与会话持久化（可选本地存储）。
5. 完整 WCAG 审计与多语言；PWA 离线包以支持无网教学。
