# 02 · 架构与双版本差异

## 在线版模块架构（纯前端 ES Modules）

```
qoder-sites-demo/
├─ index.html        五入口 IA（工作台/运行分析/三维转向架/教学仿真/项目说明）+ 全部面板骨架
├─ app.js            工作区导航、相机视角、单一渲染循环、移动端抽屉、加载/重试、__railLab 调试口
├─ core.js           加载自包含 GLB + viewer-data 契约，重建 layer/holder/spin/link 装配 rig
├─ interactions.js   射线拾取零件、高亮/隔离/透明、传感器测点与方向箭头投影、标签避让
├─ analysis.js       CSV 校验、统计、阈值事件、回放状态机与场景判定（与原 Python 规则同口径）
├─ charts.js         Canvas 三通道曲线、超阈值点、事件带、游标与拖拽寻址
├─ workspace.js      数据源/统计/事件/证据面板 + 统一时间轴，驱动曲线与三维同步
├─ viewer-dock.js    视图与渲染控制坞（inspect/motion 常驻）：光照/显示/相机/质量实时调节 + PNG 导出
├─ demo-guide.js     三分钟导览：每步驱动真实工作区 handler，无硬编码跳过
├─ styles.css        工业暗色视觉系统、响应式、焦点可见、reduced-motion、自定义滚动条
├─ assets/           viewer-data.json（零件契约/传感器/连杆/常量）、演示 CSV
├─ bogie.glb         自包含三维装配模型（Blender 导出，Y-up→Z-up 还原）
└─ tests/            expected.json（Python 基线）+ tests.js/index.html（56 项浏览器单测）
```

依赖：仅本地 vendored **Three.js r180**（`three` + `three/addons` import map），**无 CDN、无后端、
无新增运行时依赖**。所有计算在浏览器本地完成，CSV 不向云端上传。

## 数据流（闭环）

```
CSV / 演示批次
   → analysis.js 校验 + 统计 + detectAnomalies（|a|>阈值，分轴）
   → workspace.js 统一时间轴 state{position,index}
   → charts.setCursor（曲线游标） + rig.pose（三维教学运动） + 证据面板（行号/观测表）
   → 事件点击 / 曲线拖拽 / 时间轴拖拽 反向 seek，三者保持一致
```

关键一致性：曲线游标、时间轴读数、三维姿态、证据面板行号**共用同一个 `state.index`**，
任何一处 seek 都同步其余三处（`workspace.js:172-189` tick、`charts.js` setCursor、`core.js:116-130` pose）。

## 与 Python 完整版的口径一致性

- 判定规则：`|a| > 阈值` **严格大于**、**分轴统计**（`analysis.js:316-318` exceedance、`:356-397` detectAnomalies），
  与 `rail_vehicle` 原规则一致。
- 长采样间隔判定：`gapCutoff`（`analysis.js:429`）= 3× 中位间隔，间隔处标记「无当时观测」。
- 行号溯源：解析时记录 `csv_line`（`analysis.js:265`），事件/观测表透传（`:416`）。
- 基线对齐：`tests/expected.json` 由原 Python 规则生成；`tests/tests.js` 在浏览器重算并逐项比对，
  **56/56 通过**（含 demo-1=2 事件/5 点、demo-2=4 事件/9 点、边界乱序/重复时间戳用例）。

## 双版本差异（诚实边界）

| 能力 | 本地完整版 | 在线参赛版 |
| --- | --- | --- |
| 登记配置转换 / 传感器台账 | 有 | **无**（在线版无登记台账，未做幅值/偏置/坐标转换） |
| 车辆整备台账 / vehicle_id 强校验 | 有 | 仅要求非空 |
| 实车运动重建 | 研究性 | **无**（三维为预设教学示意，类别 C） |
| 故障诊断 / 安全结论 | 不输出 | 不输出（明确声明） |
| 数据上传 | 本地数据库 | **不上传**（浏览器本地解析） |

在线版以 A（原始测量/虚构示例）、B（登记配置转换·未应用）、C（三维示意运动·非积分重建）
三类标注数据来源与运动性质（`workspace.js:228` renderSource），避免把虚构/教学/实测混淆。
