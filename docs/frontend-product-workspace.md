# 前端产品工作台

本阶段从 `codex/unified-workbench-v1` 的 `4434025` 开始。继续使用 Streamlit、SQLite 及现有分析引擎，保留本地启动方式和公开演示模式。此前文档中的四入口和标签页是历史设计。

| 分区 | 入口 | 变化和保留的能力 |
| --- | --- | --- |
| 工作空间 | 工作台、车辆管理、数据管理 | 原来收在高级工具中的数据总览成为首页。建档和 CSV 校验、导入各有一个直接入口。首页的车辆、批次和采样点来自本地数据库；异常区段数只描述最近选中批次及当前预览阈值。最近分析仅记录本会话实际执行的分析。 |
| 核心分析 | 运行分析、异常检测、批次对比、AI 智能分析 | 单批次统计只计算当前范围。曲线、规则事件和同车批次对比各有独立入口；AI 仍按证据和范围校验，未配置服务时可以核查 Python 证据。 |
| 工程应用 | 三维可视化、分析报告 | 复用现有离线 GLB、视角、剖切、量测、零件和回放工具。报告显示将使用的车辆、范围和样本数，用户主动生成和下载 PDF。合格的三维观测对照仍可附入报告。 |
| 专项工具 | 虚构数据分析、演示中心、驾驶舱、振动与平稳性、多车对比、机器学习 | 保留已有算法和实验入口；采样规则和辅助说明留在使用它们的页面内。公开模式仅显示可以离线使用的虚构演示功能。 |

从「运行分析」切换到异常或报告会保留来源、车辆、批次、时间和阈值。从异常事件进入三维，定位到实际命中的批次记录；浏览整批时仍可使用完整时间轴。返回保留原范围。当前匹配的统计结果也可以直接从侧栏送入 AI 证据页。侧栏设置保留深浅两种配色；选用另一主题会开启新会话。

报告、批次和历史页面仍使用现有业务数据与校验。传感器测值、规则异常、三维示意和 AI 推测分别展示，均不用于故障确诊或安全决策。此版本不改变数据库表、GLB 资产、Windows 启动器，也不重建冻结的 V0.5 公测包。

## 本地验收入口

- `pytest -q`：页面路由、数据上下文、异常与回放证据、报表、公开数据隔离及原有计算。
- `node scripts/check_frontend_product_browser.cjs http://127.0.0.1:8572 <截图目录>`：以两个虚构历史批次启动完整模式测试实例并关闭 AI，验证两种桌面尺寸和全套直接入口。
- `scripts/check_product_browser.cjs` 同时支持公开虚构模式和隔离空库的车辆建档与 CSV 导入；`scripts/check_analysis_workbench_browser.cjs` 专门覆盖三维对照、证据返回和 PDF 流程。浏览器运行说明见各脚本头部。

## 导入到报告流程补充（2026-11-18）

- 数据导入回执和近期导入列表可直接打开所选车辆批次的异常页。多车 CSV 使用已选车辆的批次进入分析。
- 三维历史回放加宽观测面板，分行显示 UTC 日期、观测时间和批次样本位置；采样间隔内仍明确提示显示的是间隔前的最后一次观测。
- 报告生成前显示数据来源、车辆、批次、样本数、规则异常数和阈值。常规时间筛选包含结束秒内的记录；从三维返回的精确观测窗口按批次样本行显示，同一时间戳的记录也能区分。

## 首次使用引导与三维报告入口（2026-11-18）

- 没有已导入的批次时，工程工作台的「下一步」同时提供登记或导入，以及「打开内置虚构演示」。演示使用同一个运行分析页；选中真实数据时，可切回「历史导入批次」。
- 从运行分析或异常检测打开三维回放后，可返回原页面，也可直接「按原分析范围准备报告」。该入口使用进入三维前的车辆、批次、时间或样本范围与阈值，用户在报告页核对后主动生成 PDF。三维中的播放位置和阈值调整不覆盖原范围；通过证据跳转时仍提供返回证据核查。
- Windows Edge 在 1366×768、1920×1080 验证公开演示、离线证据和 54 部件 GLB；在 1366×768 的本地空库验证直接打开 120 条虚构观测，返回首页后车辆、批次和采样点均仍为 0。之后登记虚构车辆，导入 3 条观测，回查第 2 条超阈值记录，并从三维打开原范围报告并下载 PDF。
- 全量回归：547 项测试及 317 个子测试通过，包含三维阈值改动不影响原报告阈值的测试。未调用在线 AI，冻结的 V0.5 ZIP 的 SHA-256 未变。

**首次使用者走查建议：**在独立本地测试目录打开工程工作台，先用内置虚构演示走到异常、三维与报告；再返回首页尝试登记车辆和导入虚构 CSV。请记录第一次找不到的入口、误以为会被写入数据库的操作，以及是否看懂「三维当前读数」和「PDF 范围」的区别。
