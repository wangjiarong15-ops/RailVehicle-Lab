# Blender 建模与 GLB 装配约定

在 Windows 或其他系统使用 Blender 4.5 LTS 运行以下命令。PowerShell 中，若 Blender 不在 PATH，可将 `blender` 换成 `& 'C:/路径/blender.exe'`。

```powershell
python scripts/export_bogie_webgl.py
blender --background --factory-startup --python-exit-code 1 --python scripts/build_bogie_blender.py -- --blend rail-bogie.blend
python scripts/validate_bogie_glb.py
```

默认输出到 `rail_vehicle/assets/bogie_viewer/bogie.glb`，也可用 `--output` 指定路径。`--blend` 生成可编辑的 Blender 场景，可省略。建模脚本和零件参数可用于重新生成资产。应用和 GLB 结构校验均无需安装 Blender。GLB 内嵌几何和金属度、粗糙度材质，不使用外置纹理、压缩解码器或内置动画。

尺寸以米为单位。Blender、Python 几何和工作台采用 X 纵向、Y 横向、Z 向上。导出时写入 glTF 标准的 Y 向上坐标，浏览器加载后还原到工作台坐标。模型的轴距为 2.60 m，左右车轮中心间距为 1.76 m，踏面名义半径为 0.420 m，轮缘最大半径为 0.456 m，轴箱中心间距为 2.40 m，构架总长为 3.72 m。这些是通用示意尺寸，不代表轨距、许可间隙或任何具体车辆。

静置示意的轨顶位于 Z = 0。GLB、程序化回退与 Plotly 兼容视图共用名义踏面半径、示意运行带和轨头宽度。轮缘位于轨头内侧，抛光轨顶与轨头承托部分分开建模。GLB 校验读取导出的网格，检查四轮踏面与轨顶对齐，以及轮对在静置轴线绕 Y 转动时的几何包络。此校验不覆盖示意横移和摇头，也不求解动态接触、载荷、磨耗或轮轨力。

精修版 GLB 将轴箱铸件、端盖接缝、弹簧安装座和连接耳分层表现。电机有散热筋、端盖与接线盒，齿轮箱有分型面与联轴端，制动盘和夹钳留有示意间隙。两台电机分别通过两处铸造安装耳连接中横梁底面，侧梁两端的外侧法兰标出端横梁连接位置。新增细节归入原有部件，拾取、运动、拆解和书签继续使用相同标识和枢轴。Blender 4.5.3 导出为 54 个部件、58 个网格、47,356 个三角形、1,389,556 字节。

构架采用哑光蓝灰喷涂，一般车轮钢面和轴箱铸件比加工面更暗、更粗糙，轮踏面及相邻过渡带保留较亮反射。二系空气弹簧的橡胶气囊用低反光表面，端盖仍使用金属材质。这些表面共用十种内嵌材质。

动画净空校验以装配状态下各稳态模式的一圈为范围，取 16 个相位，包含振动峰值。在网格水平投影重合处检查横梁与四个车轮、同侧侧梁与四个轴箱的垂直间距，采用 2 mm 的示意模型检查阈值。检查范围限于这两组构件和离散姿态。

完整的 54 项清单在 `rail_vehicle/assets/bogie_viewer/model_contract.json`，由 `rail_vehicle/bogie_model_spec.py` 生成。后缀 `a`、`b` 分别表示 X 为 −1.30 m 和 +1.30 m 的轮对。`l`、`r` 分别表示 Y 负侧和正侧。

| 根节点下的层 | 零件 | 播放时的行为 |
| --- | --- | --- |
| `rail_frame` | 左右侧梁、横梁、上弹簧座、空气弹簧、电机 | 随构架横移、升沉和摇头 |
| `rail_wheel` | 两根车轴、四个车轮、四个轴箱、下弹簧座、齿轮箱、制动盘和卡钳 | 随走行机构运动；只有车轴、车轮、制动盘绕各自轴心的 Y 轴转动 |
| `rail_links` | 一系螺旋弹簧、减振器、导向件、传动连接和卡钳支撑 | 按 Python 定义的两个连接点更新姿态；减振器采用刚性滑移，其他连杆保留原伸缩示意；拆解时按层移动 |

每支减振器在原部件节点下保留两个网格，使用 `rail_damper_segment` 属性标记 `body`（缸筒）和 `rod`（活塞杆）。缸筒对齐走行机构端，活塞杆对齐构架端，并沿缸筒内孔滑动。两段保持固定尺寸，拆解时回到名义伸出位置，共用同一个零件编号。GLB 最深插入和最大伸出按各稳态示意模式的 16 个相位检查，要求至少 10 mm 插入量和 2 mm 径向净空。这些是示意模型校验值，不能用于判断真实减振器行程、阻尼或故障。程序化回退和 Plotly 用简化圆柱表现固定长度的两段。新版工作台也能打开早期单网格 GLB，早期资产沿用整件伸缩且不符合新版导出校验。
| `rail_fixed` | 轨道参照 | 保持固定 |

更换网格时保留 `rail_bogie` 根节点、四个父层、各部件的稳定名称和自定义属性、原点及静置坐标。减振器的两个网格节点保持单位变换，局部滑动方向为 Blender 的 +Y（导出后的 glTF 局部 −Z）。在 Blender 导出面板中使用 GLB、+Y Up、Custom Properties 和法线，关闭动画和 Draco 压缩。校验脚本会检查结构、坐标、内嵌资源和网格预算。前端通过 [Three.js GLTFLoader](https://threejs.org/docs/pages/GLTFLoader.html) 加载资产并检查装配层级和零件原点。

工作台用本地生成的环境反射图，加上主光、补光、轮廓光和沿 Z 轴布置的半球光。主光阴影优先覆盖装配模型和轨道，进入拆解模式时扩大范围。继续使用原有 1024 × 1024 阴影图及固定曝光。

检测到软件 WebGL 时，播放过程中按构架、走行机构、轮轴及悬挂连杆合批绘制，使用简化光照并降低绘制分辨率。单件拾取和隐藏仍使用原装配节点。暂停后恢复完整分辨率和 PBR，未启用剖切时恢复阴影。硬件 WebGL 保留 PBR 播放。

四根活塞杆在软件播放时各有一个独立绘制批次。Edge 的软件 WebGL 在 1920 × 1080 下以正常运行模式交替测量新旧版本，每版取三次样本的中位数。帧率由 33.6 变为 33.4 FPS，绘制调用由每帧 25 次增至 29 次。此结果仅代表本机正常运行场景的对照。

教学动画按 2.4 秒循环，可在跨圈时保持正转或切换倍速。Three.js 与 Plotly 的车轮标记采用相同转向，绕 Y 轴正转时，轴心前方的标记朝轨面下降。历史回放以批次时间为准，循环窗口跳回起点时重新对齐示意相位；遇到长采样间隔时，模型立即回到中立静止姿态，侧栏仍把间隔前的最后一次观测单独标明。播放倍速和示意转角均不代表测得的车轮转速。

在视窗工具栏打开「零件清单」，可按中文名称、类别或稳定编号查找零件。选中后可聚焦、隐藏、恢复所选，或使用「仅看所选」观察被其他构件遮挡的部位。退出隔离会恢复隔离前的类别和单件隐藏设置。类别关闭的零件仍可搜索，重新显示时请启用对应类别。

在暂停且未拆解时，点击「两点测距」，再依次点击两个可见表面。视窗会标记测点，显示直线距离和从第一点到第二点的有符号 X、Y、Z 差值，单位均为米。可清除测点，也可点击第三点开始下一次测量。播放、改变模型姿态或可见零件会清空测点。这些读数用于比较通用示意模型中的距离。

点击「剖切视图」，选择 X 纵向、Y 横向或 Z 垂向，拖动滑块设置切面在模型坐标中的米制位置。「翻转保留侧」可查看切面的另一侧，关闭剖切可恢复完整外形。剖切时可以选中、聚焦和测量仍可见的表面。移动或关闭切面会清除原测点。剖切显示现有表面，切口不生成实体截面或填充。

暂停后点击「导出检查图」可在浏览器下载 PNG。图片包含当前模型画面、所选零件、启用的剖切参数和已完成的测距读数。运行回放还会附上来源、批次编号、样本时间、速度、横向与垂向加速度及阈值状态。长采样间隔明确标为间隔前最后一次观测；正常对照图明确标为参照。GLB 和程序化几何均可在本地导出。

暂停并退出分解示意后，可从「检查视图」为当前观察位置命名并保存。书签保存相机位置、缩放、视角、零件显隐及隔离、选中零件和剖切设置。使用同一浏览器和本地地址重新打开工作台，可选择恢复或删除已存视图。恢复后仍可用左侧的观察预设重新应用页面的零件类别。书签保存在浏览器中，测点、运行数据和播放时间不写入书签。

「导出书签」会将已保存视图打包为 JSON，可在另一台机器的工作台用「导入书签」读取。导入会验证整个文件，格式不符时保留原书签。同名视图自动跳过，每个浏览器地址最多保存 12 项。恢复时请使用书签保存时的模型模式（GLB 或程序化几何）。
