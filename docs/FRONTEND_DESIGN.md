# 前端设计与验收说明

## 设计系统

使用 Streamlit 原生组件和 `.streamlit/config.toml` 主题，不依赖外部字体或前端框架。视觉精修使用两处稳定的布局 test ID 调整顶部间距；其余 CSS 仅作用于自有命名类和组件键，不覆盖大量内部嵌套选择器。

## 双主题视觉精修（2026-10-30）

- 默认深色：海军蓝主背景 `#091422`、蓝灰卡片 `#132338`、高对比文字 `#E5EDF8`。浅色采用浅灰背景 `#F1F5FA`、白色卡片、蓝色强调。
- `.streamlit/config.toml` 的原生 light/dark 配置负责输入、按钮、表格、侧栏与图表主题；`ui.py` 提供 KPI、标题、图表容器、状态标签、空状态、表格和按钮组件。
- 移除全局重复大标题，保留每页自己的标题。首页采用四项指标、主趋势区和右侧活动列；三通道共用 UTC 横轴，异常标记复用已有规则结果。
- `dashboard_chart.py` 只负责绘图，不重新计算指标。每个通道及异常点层最多绘制 1,200 点、最近 30 个区段；统计依旧使用完整预览组合。区段阴影仅描述首末异常样本时间跨度，不证明采样空档内持续异常。
- 原生双主题在新浏览器默认跟随操作系统，因此增加小型、固定内容的浏览器入口：使用 Streamlit 支持的 `embed_options=dark_theme/light_theme`，仅保存自有 `rail_vehicle_theme` 外观偏好，使用白名单恢复 `rail_page`。没有写入私有 Streamlit 存储键或保存分析/车辆数据。
- 初始化在页面生成完毕后执行，避免首次主题跳转中断 Plotly/NumPy 的延迟导入。首次访问可能发生一次主题加载跳转。
- 主题切换会重载页面；未持久化的 AI/实验会话结果需要重新生成，界面明确提示。数据库数据不变。存储被禁用时，当前主题 URL 仍可使用，但浏览器跨访问偏好无法保证。
- 本轮未更改算法、数据库结构、AI Provider 或 PDF 生成器。旧阶段的验收记录保留如下，不代表本轮测试数量。

## 模块分工与修改文件

- `.streamlit/config.toml`：统一颜色、字体层级、表格、圆角和侧栏主题。
- `rail_vehicle/ui.py`：分组导航、图表组件、会话内实际分析记录，不计算动力学指标。
- `rail_vehicle/dashboard.py`：只读事务中的总量、最近导入及预览查询；显式关闭连接，避免 Windows 文件占用。
- `rail_vehicle/pages/home.py`：首页与统计边界，复用原有数值计算和规则检测。
- `app.py`：路由、独立 CSV 导入入口及公开演示访问边界。
- `pages/vehicles.py`：列表、搜索、详情、弹窗、快捷分析；复用原有校验和数据库函数。
- `pages/run_analysis.py`：紧凑范围选择、速度卡片、曲线标签页及实际执行记录；原有异常/AI/报告流程保留。
- `pages/cockpit.py`、`ml_detection.py`、`vibration_analysis.py`、`fleet_comparison.py`、`ml_review.py`、`anomaly_review.py`、`demo_center.py`：共享图表组件或视觉层级；实验结果登记为真实会话执行记录。
- `tests/test_frontend.py`：新增 14 项数据口径和交互测试。
- 原有 `test_app_smoke.py`、`test_cockpit.py`、`test_demo_center.py`、`test_ml_detection.py`、`test_public_demo.py`、`test_statistics_demo.py`、`test_vibration_page.py`：保留业务断言，适配新导航、独立导入入口及合理等待时间。
- README、ROADMAP 与 `docs/screenshots/frontend-*.png`：使用说明、阶段记录和独立虚构数据截图。

未来迁移 React 可将查询和现有数值模块作为服务边界，复用数据结构及数值测试。本阶段不引入 API 服务或改变部署架构。

## 首页数据边界

1. 车辆、批次、样本总量为 SQLite 精确计数，不用演示数据填充空库。
2. 异常预览仅对应最近导入的一个车辆/批次组合，使用当前首页阈值调用既有分析器；不是所有历史异常的总和。
3. 完整组合最多预览 20,000 点；超过上限不计算部分批次指标。曲线最多显示 1,200 个按时间顺序选取的点，统计仍使用完整预览组合。
4. 数据库不存在时不创建文件，读取失败显示不适用，不误报零资产。读查询采用一致事务快照并关闭连接。
5. 最近分析记录只保存本次会话实际执行的单批次、批次对比及实验分析，按事实与选择去重、最多八条；没有新增数据库表，不表示持久化历史。
6. 公开模式不执行首页数据库查询，资产显示“—”，原有 AI 禁用和历史功能隐藏规则保持。
