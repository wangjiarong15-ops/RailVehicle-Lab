# Windows x64 独立公测清单

## 五分钟上手

1. 核对发布方的 ZIP SHA-256。可在下载目录执行 `Get-FileHash -Algorithm SHA256 RailVehicle-Lab-V0.5-Windows-x64-Beta.zip`。
2. 完整解压。在解压目录执行 `RailVehicle-Lab.exe --check` 核对模块和资源，再正常双击 EXE。
3. 打开「工程研究」。在「数据来源与附件」选择「合成频谱双批次」，绑定另一批作为对照。
4. 新建「比较两批运行质量」，生成计划并核对预算，再批准执行。查看证据、追加一个工程目标并导出报告。
5. 打开「动力学仿真 → 高级轮轨动力学」，查看求解时间轴、前轴左右轮重和双视窗。公开柔度校准位于「工程验证中心 → 物理校准」。虚构数据用于体验。
