V0.4 本地验证：纯 Python 时间轴测试、Streamlit 页面交互测试、临时 SQLite 导入至回放端到端测试，以及真实浏览器中对自动刷新、暂停、重置、倍速和异常提示的检查。浏览器演示使用内置虚构数据，不需要 API Key。
