## 单批次 PDF 采样质量闭环（2026-11-01）

继续 `codex/sampling-quality`，基于已上传提交 `44e1554`。
单批次 PDF 第五节扩展为采样概览与数据质量检查，使用当前筛选样本和检查规则重新计算事实，
记录基准来源（自动中位数或手动指定）、基准秒数、倍数、严格大于的判定界限、重复时刻额外记录、
当前输入倒序及长间隔总数。最多附上前 20 处长间隔的 UTC 起止和间隔，明确展示数与全量总数。
不足两个时刻、未触发规则及需回查三种状态分别说明，不把检查结果解释为数据合格或车辆安全。

采样检查组件返回当前结果；报告缓存指纹纳入检查结果与规则、完整筛选样本、车辆和原分析选择。
改变基准来源（即使数值相同）、间隔、倍数或样本后，旧 PDF 下载失效，必须主动重新生成；
历史与虚构演示缓存独立，保持既有统计、异常算法及 AI 输入不变。调整异常回查窗口仍不影响报告。
修正曲线章节标题跨页及未生成 AI 时单独占末页的问题，并用 ASCII 页脚分隔符避免 CID 字体缺字。

验收：新增 8 项测试，完整 pytest 为 **425 passed、275 subtests passed、2 skipped**；
跳过 Windows 专用锁和启动测试。编译、`pip check` 与差异检查通过。
AppTest 验证历史规则变更后下载消失、重新生成、倍数变化、虚构演示中自动转手动的缓存失效，
并确认统计和 AI 输入不变、私有历史缓存不受演示操作影响。
生成正常采样、重复时刻、长空档及 209 处长间隔四类虚构 PDF，页数分别为 3、3、4、4；
使用系统 Poppler 与本地 CJK 字体逐页渲染检查中文、规则、UTC 明细和分页。
测试 PDF 为临时验收材料，不是实车记录。未调用真实 AI、未重建 Windows 包、未合并 main。

## 采样质量回查（2026-11-01）

基于 `codex/windows-portable` 的 `3b61882` 继续开发，独立分支 `codex/sampling-quality`。
源码中已有采样概览、振动指标、机器学习及异常事件回查，本阶段补齐可操作的时间采样检查，
不重复已有功能。

- CSV 预览按车辆分别检查共享 UTC 时刻的额外记录、原文件相邻同车记录倒序，以及长采样间隔。
  不把不同车辆同一时刻算成重复；格式错误时不展示部分质量结果。
- 单批次及虚构统计演示根据当前筛选样本检查，可手动指定预期间隔或使用去重间隔中位数；
  默认严格大于基准 3 倍提示长间隔。明细列出 UTC 起止与间隔，最多 100 处，全量计数。
- 不删除、插值、补点或改变阈值异常；检查规则不进入现有 AI/PDF，调整规则不影响其缓存。
  原 CSV 倒序须在导入预览核查，历史数据已排序；自动中位数不能检出所有规则性缺测，
  无提示不等于质量合格。此阶段尚未把质量检查写入报告。
- 在全新依赖环境复现并修复原便携版的隐式 `toml` 依赖问题：Python 3.11+ 使用 `tomllib`，
  Python 3.10 显式声明 `tomli` 依赖。缺失或损坏配置仍不读取全局密钥。
