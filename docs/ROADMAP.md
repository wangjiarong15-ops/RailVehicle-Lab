# 功能里程碑与后续路线

版本以功能验收为准，本文不改变 Python 包版本号。

| 阶段 | 交付范围 | 状态 |
| --- | --- | --- |
| V0.1–V0.3 | 车辆管理、CSV 导入、动力学统计、阈值异常、时间筛选、多批次对比、PDF 和证据约束的 AI 解读 | 已实现 |
| V0.4 | 历史数据模拟驾驶舱：选择车辆/批次、播放/暂停/重置/倍速、动态仪表与曲线、超阈值提示、离线虚构演示 | 已实现，验收见测试与浏览器演示 |
| V0.5 | 本地 Isolation Forest、独立参考/检测批次、模型与规则对比、离群分数及虚构实验 | 已实现，验收见测试与浏览器演示 |
| V0.6 | 振动与平稳性探索：采样质量门槛、时域振动指标、滑动 RMS、Welch PSD、频带 RMS 和已知信号演示 | 基础分析已实现；标准舒适等级尚未实施 |
| V0.7 | 多车辆运行表现对比，明确车型、工况和采样可比性 | 尚未开发 |

| V0.9 | 竞赛演示流程、展示素材和部署 | 尚未开发 |
| V1.0 | 完整功能与安装运行验收 | 尚未开发 |

当前边界：CSV 为离线批次数据；已具备无监督机器学习离群基线，但没有设备实时采集、真实故障标签验证或已认证的舒适性/安全评价。模型、AI 与阈值结果不能作为真实故障或铁路运营安全结论。

V0.4 本地验证：纯 Python 时间轴测试、Streamlit 页面交互测试、临时 SQLite 导入至回放端到端测试，以及真实浏览器中对自动刷新、暂停、重置、倍速和异常提示的检查。浏览器演示使用内置虚构数据，不需要 API Key。

2026-10-25 验收记录：新增 16 项测试；完整 `python -m pytest -q` 为 223 passed、142 个子测试通过，无失败和跳过。`python -m compileall -q rail_vehicle tests app.py` 与 `git diff --check` 通过。真实浏览器验证自动刷新、暂停、重置、2× 倍速和异常提示；本地 Streamlit 健康检查 HTTP 200。截图位于 `docs/screenshots/cockpit-history-replay.png`。

V0.5 验收记录（2026-10-25）：新增 16 项测试；完整 `python -m pytest -q` 为 239 passed、154 个子测试通过，无失败和跳过。编译与差异检查通过。经用户授权在项目虚拟环境安装可选 `.[ml]` 依赖，本机 scikit-learn 为 1.9.1。真实浏览器中主动运行本地模型并验证参数变化清除旧结果；应用健康检查 HTTP 200。独立虚构实验的 160 条检测样本中模型标记 20 条、规则标记 5 条、重合 5 条；这些数字不是故障准确率。截图位于 `docs/screenshots/ml-anomaly-experiment.png`。

V0.6 不将低频样本、瞬时 RMS 或去均值振动强度直接描述成标准合规/舒适等级。当前不包含标准频率加权、Sperling 指标、重力/姿态校正或传感器测量链路验证。

V0.6 基线验收记录（2026-10-25）：新增 18 项测试；完整 `python -m pytest -q` 为 257 passed、168 个子测试通过，无失败和跳过。编译检查、差异检查、`pip check` 及 Streamlit 健康检查通过。本版复用已安装的 NumPy/SciPy，没有额外安装依赖。真实浏览器对 100 Hz、3,000 条虚构样本计算出横向 1.5 Hz、垂向 6 Hz 主峰，验证 PSD、滑动 RMS、时间范围失效和短记录停用频域功能。截图位于 `docs/screenshots/vibration-analysis.png`。

下一里程碑 V0.7：同工况下的多车辆运行表现对比，明确车型、质量、速度与采样口径，避免把工况差异当成车辆优劣或故障判断。
