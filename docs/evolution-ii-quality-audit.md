## 首页意见逐项复核

| 意见 | 结论与证据 |
| --- | --- |
| 横向曲线与菱形不一致 | 基线上一阶段已解决峰值时间配错。保留同一组原始行，规则标记与基准轨迹数值逐点相等。本阶段为未抽样的小批次连接相邻观测，遇到重复时刻或长间隔时断开，超载时保留原始散点。`test_connected_samples_keep_gaps_same_time_event_and_exact_hover` 与 30,000 点用例核对。 |
| 异常点和区段混用 | 一条观测可能贡献两次通道超阈，按行只计一次。区段另按方向合并，首页、异常页和报告分开命名。专项报告用例覆盖 3 条观测、6 次通道超阈和 4 个区段。 |
| 方向、合并连续性和采样空档 | 实现依旧对每个方向独立执行 `abs(a) > threshold`，按 UTC 稳定时间顺序处理。该方向出现未超阈观测才结束连续区段。正负变化与时间空档均不拆区段，空档只影响连线和回查解释。规则同步进 PDF。 |
| 图例位置 | 移入 Plotly 图框。图例说明菱形、区段、同刻区段与阈值。无法通过图例误隐藏统计证据。 |
| 首末为同一时刻 | 时间跨度用竖线显示，峰值菱形落在该观测原值。该时刻可能有多条源观测，列表显示实际样本数。 |
| 时间轴、悬停及高亮 | 基线已有统一 x 轴。本轮保留同步游标，悬停来自基准轨迹，标注原始行、实际单位和阈值状态，菱形叠层不单独抢占悬停。独立 Edge 触发真实悬停并核对三通道响应、区段和三维入口。 |
| 唯一当前页 | 路由归一在现有 `render_navigation`。界面回归会在每个桌面路由完成渲染后计数，要求仅有一个侧栏路由被标为当前页。移动端初始关闭侧栏，保留原生打开按钮与设置。 |

实际记录、工业校准、适用标准限值与真实 API 未参与此轮。移动 Edge 的 390×844 仿真可检查基本视口布局与导航，真机触控、长时 GPU 负载、整站无障碍及发布安装验收仍需独立设备。当前浏览器截图均使用虚构数据库。

## P2 绘图性能对照

绘图标线、事件范围和阈值注释改为批量提交，减少 Plotly 因逐一追加元素而重复验证布局。同一虚构输入、同一浏览器数据编码所用的 JSON 格式，在本机预热后交替执行两版本各七次。120 行、41 段的数据，绘图及 JSON 序列化中位数由 472.4 ms 至 31.5 ms，JSON 为 67,717 → 71,699 字节。30,000 行、10,286 段的数据由 549.2 ms 至 79.4 ms，JSON 为 420,881 → 436,285 字节。页面均最多绘制 30 个区段的标线。这些计时只包含图表构建及序列化，浏览器交互、数据库读取与异常检测需要另外计时。

## 验收证据

- `python -m pytest -q` 最终通过 717 项及 324 个子测试，零失败。Python 编译、修改过的 JavaScript 的语法、`pip check`、Git 差异、Phase 8 跨语言契约及 54 部件 GLB 装配通过。旧图表测试由固定散点模式改为核对有限范围内的折线和断线，原始采样数值断言继续执行。
- 专项 Edge 流程验证了 76 条观测、1.2 m/s² 阈值和同一批次由分析进入仿真后返回、三维核查、Copilot 窗口及 PDF 生成。另验证同批次、同阈值的 1–76 和 1–120 两条历史分别出现在服务重启后，并显式恢复后者。
- Edge 合并运行验证 Copilot、动力学联动、界面、传感器和本机模拟 AI。合并运行中的三维播放超时在独立模型套件中复测通过。报告刷新后回到异常检测曾出现日期控件丢失保存值，显式回填 UTC 边界并提供整批重置后，两个桌面视口均保留 76 条观测、1.1 m/s² 与原垂向事件。前端报告跳转等待控件完成重绘，独立前端套件也在两个视口生成并下载 PDF。现有交互与证据断言均保留。
- 最终桌面界面验收覆盖 18 个路由、两个分辨率及两个主题，移动验收覆盖 9 个路由和系统设置。移动首页图表另断言图例、工具栏和通道标题在浏览器内互不遮挡。
