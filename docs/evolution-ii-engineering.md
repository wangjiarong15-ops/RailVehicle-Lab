# Evolution II 第二阶段工程深化

基线为 `38e49cab`。第一阶段已验收的数据范围、异常回查与 PDF 路径继续复用。三维检查从现有 Blender 脚本、glTF 层级、54 个稳定部件编号、轮轨包络和减振器校验开始。所用构型是通用双轴动力转向架，名义轴距 2.60 m。现有代码按安装层级组织侧梁、轮对、轴箱、传动与制动、一系连接及二系空气弹簧。尺寸和材质均为工程示意。

## 装配和检查

GLB 保留原有零件和枢轴。校验器读取两侧空气弹簧的原始网格，核对枢轴与下安装面、名义高度 0.324 m、端板和气囊材质。程序化车体安装板只在有二系计算数据的视窗中出现。它连接左右上安装点，随计算横移、侧滚或局部升沉更新。气囊采用端点约束的近似缩放与倾转，不能用于橡胶形状、板接触或实际净空评估。版图中的减振器仍用刚性活塞杆和固定尺寸缸筒的滑移模型。抗侧滚以等效刚度参与求解，尚无独立杆件的装配几何。既有教学场景、历史回放和计算仿真保持各自的数据来源。当前环境未检测到 Blender，本轮验证的是既有 GLB 及浏览器端装配。

零件清单按总成及 A/B 轴位置展开，支持搜索、双向选择、显隐、独立显示、局部透明和剖切。传感器面板继续按登记位置与通道显示证据。暂停时可主动记录当前所选部件、观察视角、表面模式、独显及剖切，使用本地 Copilot 工具核查。模型检查记录只含视图状态。

## 横移与侧滚计算

横向模型 `rail.carbody-lateral-roll.v1` 使用 `q = [y, φ]ᵀ`。`y` 为车体质心横移（m），`φ` 为绕 +X 右手侧滚（rad），正角使 +Y 侧升高。`h` 为质心至二系支承面的高度，`b` 为两空气弹簧中心半距，`y_b` 为给定的转向架横向支承输入。车体支承面相对横移为 `y + hφ - y_b`，左右垂向相对位移分别为 `−bφ`、`+bφ`。

```text
d = [1,h]ᵀ
M = diag(m,Ix)
C = cy·d dᵀ + diag(0, 2b²cz)
K = ky·d dᵀ + diag(0, 2b²kz + k_ar)
M q̈ + C q̇ + K q = d·(ky y_b + cy ẏ_b)
```

质量 `m` 用 kg，惯量 `Ix` 用 kg·m²，`ky/kz` 用 N/m，`cy/cz` 用 N·s/m，`k_ar` 用 N·m/rad。`kz/cz` 分别是每侧垂向参数，`ky/cy` 是二系总横向参数。初位移和速度取静平衡的零值，轨面给定位移与其解析导数按 `x = vt` 输入。局部激励为单段余弦脉冲，周期激励在首个波长内渐入。零输入、有限局部输入、周期输入均可导出工况复算。动力学假设忽略左右轮轨力、构架侧滚、侧向轮轨蠕滑、悬挂非线性和主动控制。

数值积分与整车垂向模型复用平均加速度 Newmark。默认步长 1 ms，5 ms 输出一次。接受的工况范围由 `LateralCase` 约束。工况实验可调整质量、惯量、速度、悬挂参数及抗侧滚刚度，输出位移、速度、加速度、RMS、固有频率、对照与 ±5% 局部敏感性。结果包含模型版本、工况参数、步长和内容摘要。浏览器通过同一索引控制计算曲线、播放、倍速、暂停、逐帧和峰值定位。动画显示使用独立的统一倍率，并限制示意运动，数值表继续使用原计算量。

独立 DOP853 对照 2 s 局部激励计算。1 ms 步长的最大横移误差为 4.60×10⁻⁸ m，最大侧滚误差为 5.11×10⁻⁸ rad。步长减半后两项误差约为原来的四分之一。回归还检查了零输入、矩阵正定、二系左右映射、响应方程残差和激励结束后的能量耗散。默认教学工况输出横移绝对峰值 5.884 mm、侧滚绝对峰值 2.384 mrad、横向加速度 RMS 0.03827 m/s²。

## Copilot 工程任务

在横向仿真页可将当前已计算工况带入 Copilot。指令「计算侧滚，抗侧滚刚度提高20%」经过本地规划和参数校验，运行基准和变更工况，展示实际曲线、证据编号和三维计算动画。「再把速度设为25 m/s」沿用上一轮已验证的比较参数。保存的对照工况能载入仿真台复算。已记录的三维检查可在会话中以「查看当前三维检查状态」核对。对话归档继续按可审阅文本保存，仿真和三维状态可由用户选择恢复，再显式选择问题复算。历史文本本身不触发执行。车载数据分析、教学计算与 AI 解释保持既有证据边界。

## 验收

- 在本机隔离数据库执行 `python -m pytest -q`。725 项及 324 个子测试通过。`python scripts/validate_bogie_glb.py` 校验 54 个部件、58 个网格和 47,948 个三角形。跨语言契约校验、Python 编译和 JavaScript 语法检查通过。

- `--suite evolution-ii` 另在新 Edge 会话重新上传归档，复验仿真工况和三维检查状态可以恢复。恢复动作未自动执行工具。验收日志与截图位于 `tmp/evolution-ii-stage2-edge/run-_gc2xs3e/` 和 `tmp/evolution-ii-engineering-final/run-uv3sflb_/`。软件 WebGL 在这台电脑的正常运行检查记录 16 FPS 和 32 个绘制调用；真实 GPU 性能和真实车辆装配净空仍需相应环境验证。
