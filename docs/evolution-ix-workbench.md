# Evolution IX 工程工作台

## 基线与阶段

基线为 `codex/evolution-viii-calibration` 的 `ebd6e409`，其本机验收为 779 项 pytest、325 个子测试。重新核对了 VIII 冻结 ZIP 的 SHA-256，并正常推送该分支。IX 使用独立分支 `codex/evolution-ix-workbench`。使用上一阶段真实 Edge 的 1366×768、1920×1080 截图作为界面基线。

## 研究工作流

1. 打开首页「工程研究」，或在 Copilot 切换到同名工作区。「数据来源与附件」可绑定历史窗口、已有虚构批次或两组 50 Hz 合成频谱批次。创建任务时把所选样本固定在本机 SQLite 中用于重启复核。任务的观测上下文在各轮保持一致。
2. 填写目标和成本，选本地工程分析或已配置的云端结构化规划。每轮查看真实的工具、参数及依赖，再批准加入本机队列。设置了优先级的任务优先领取，同优先级按创建顺序执行。交互调度最多一个工作进程同时执行已审批任务。
3. 可在一个任务完成本轮后复核、提出新目标或归档。离线规划按目标组合不同工具，允许从先前的 DOP853 结果追加 RK45 独立复算。云端根据输入上下文状态与上轮运行信号流式生成下一轮的结构化依赖图。校验拒绝未知工具、循环、超额成本和非法参数。
4. 运行中可暂停、取消。每个步骤的输出、来源、校验摘要及本机执行时长随完成提交。继续会复用已保存步骤。若工作进程异常中断，租约过期后恢复至可调度状态，由工作台重启待执行队列。
5. 在结果区选单工况或同条件双视窗回放。导出的 JSON 不附入原始任务快照。PDF 提供本轮步骤及证据编号。

```mermaid
flowchart LR
  UI[工程研究工作台] --> P[本地组合或云端结构化提案]
  P --> G[依赖与预算校验]
  G --> A[用户审批]
  A --> Q[(SQLite 待执行队列)]
  Q --> W[独立 Windows Spawn 工作进程]
  W --> T[白名单工程工具]
  T --> E[(逐步提交的证据)]
  E --> UI
```

工具协议定义输入校验、领域单位、资源成本、只读权限、上下文需求、输出类型与执行证据。已接入采样质量、统计、异常、频谱、双批次、传感器、资料检索、结构视图、31 自由度、CONTACT 柔度、合成悬挂辨识、Pareto 和证据汇总。每任务最多 4 轮、18 步、34 成本单位和 220 秒累计活跃时间。云端每任务最多 3 次，每次至多 1,200 个输出 token。云端协议发送用户当轮目标、工具规格及压缩状态信号，不包含原始观测、统计数值、文件内容或私有标识。每轮发送前须明确同意，执行前再次核准。真实提供方需单独授权验收。

## 三维实现

沿用 54 部件 GLB 检查和选择映射，三维检查的部件树放在左侧。整车求解视图增加车体底架、横梁、空气弹簧座、中心牵引连接、横向及抗摇头减振器和抗侧滚连杆。程序化资产 `vehicle-details.js` 保存安装端点映射。车体窗口按批实例化，轨道按头、腹、脚三段绘制。动态构件跟随各自所在求解刚体，右侧显示车体相对横移、垂移、侧滚、点头、摇头、行驶里程及前轴左右轮重。

连接类型参考公开构型。几何尺寸取教学近似，制造、公差或干涉需独立检验。里程为运行条件，车体其余五个分量来自求解。CONTACT 居中左轮刚度偏差和悬挂辨识证据边界沿用 VIII。[FRA 无摇枕构型说明](https://railroads.dot.gov/sites/fra.dot.gov/files/2022-01/HSR%20Noise%20Mitigation%20Procedures.pdf)

性能工具分别记录 GLB 创建时延、双视窗提交计数、绘制调用、两视窗三角形，以及捕获画布后的视频呈现回调和帧时间分布。捕获视频计数反映浏览器捕获与合成路径，独立显示器刷新验收需在目标设备执行。单进程与两进程性能对照使用同样车辆模型、时长和积分容差。

## 实际验收

- 完整 Python 回归 783 项通过，另有 325 个子测试通过。教学动画修复后，轮轨和任务队列专项 17 项再次通过，Python 编译、JavaScript 语法、双版本契约、GLB 检查及 Git 差异检查通过。GLB 包含 54 个部件、58 个网格、47,948 个三角形，大小为 1,457,452 字节。
- 隔离 Edge 检查覆盖 1366×768 与 1920×1080 深浅色、390px 导航、研究任务空状态及 115% 缩放。原有教学场景在首轮长套件中触发 800 ms 快照超时并停播。修复后周期教学模式可本地继续，显式暂停保持不动，历史批次仍遵守快照边界。该模型专项从低于 5 FPS 恢复到 11 FPS，并验证七种场景、剖切、书签、离线证据及 GLB 缺损回退。
- 本地工程研究验证五类目标。横向优化算例实际调用 DOP853、Pareto 及独立 RK45。基准与候选横向加速度 RMS 分别为 0.054596 和 0.044834 m/s²，候选 RK45 复算为 0.0448340 m/s²。双批次比较、柔度校准、频谱及线路对比也执行各自的白名单工具。本机模拟云端根据第一轮异常结果发起依赖该步骤的频谱分析，两轮分别获得用户同意和执行审批。真实云端未验收。
- 真实 Edge 双视窗原生图形路径在 2.36 秒内提交 142 帧，捕获视频回调 136 次，间隔 p50 / p95 为 16.7 / 16.9 ms。GLB 加载测点 371 ms，双视窗合计 358 个绘制调用、102,904 个三角形。捕获统计不代表屏幕刷新率。
- 相同两项动力学工况串行 17.49 秒，两工作进程 14.57 秒，含进程启动，约 1.20×。进程峰值工作集约 79–80 MB，轨迹与证据一致。正常交互队列使用单并发，下列命令可在相同求解精度下重跑对照。

```powershell
.venv/Scripts/python.exe scripts/benchmark_workbench_jobs.py --output tmp/ix-compute.json
.venv/Scripts/python.exe scripts/run_browser_checks.py --suite evolution-ix
```
