# V0.5 工程验证工具包

状态为**软件流程验证**。实车、传感器和参考仪器均待独立验收。

## 准备试验文件

1. 先在「车辆管理」建立对应车辆。以 [运行 CSV 表头](running-data-template.csv) 建立 UTF-8 文件。速度填 km/h，横向与垂向加速度填 m/s²，时戳填带明确时区的 ISO 8601。空白观测应回查源文件，填零会改变观测含义。源仪器使用不同单位时保留原文件和转换记录，另存用于导入的 CSV。
2. 用 [工程元数据示例](metadata.example.json) 建立配套 JSON。按采集单填写数据来源、车辆、声明采样率、两路测点、坐标系和局部轴。将示例中的全零 SHA-256 替换为最终导入文件的值。填入接收时间基准 `utc` 或固定设备偏移 `device_offset`，后者填写 `clock_offset_s`，按「UTC = 带时区时间对应的 UTC 值 + 固定偏移」换算。示例以 `synthetic` 标记虚构数据。只有确实来自现场的记录才填 `field_declared`。
3. 在「数据导入」上传 CSV，打开「工程数据接入（可选）」并勾选附带元数据。匹配检查按单车文件执行。现有多车 CSV 可在普通模式导入，工程核对时为各车辆准备单独文件及新的 SHA-256。工程模式校验通过后，元数据和筛查结果随批次保存。
4. 在「传感器配置与数据溯源」登记同一测点的姿态、增益、偏置和核验来源。声明只用于比对，当前配置由具有现场证据的人员单独登记。检查差异字段、版本、原始行号和时间映射，再从异常事件跳入三维。三维波形和阈值沿用源读数，换算值单独显示，动力学响应使用教学假设和相对时间。
5. 同一试次提供独立参考 CSV 及仪器记录，填写试验方案规定的筛查限。下载复核 JSON，在同一会话导出 PDF。详见 [传感器标定与数据溯源](../sensor-calibration.md)。

```powershell
(Get-FileHash -Algorithm SHA256 -LiteralPath '实际文件.csv').Hash.ToLowerInvariant()
```

练习可用 `.venv\Scripts\python.exe -m scripts.make_calibration_example --output tmp/engineering-example` 生成虚构运行 CSV 和参考 CSV。元数据示例已与此试次的采样率和横向测点配套。用生成文件的摘要替换全零值。传感器姿态和增益填写方法见 [虚构练习步骤](../sensor-calibration.md)。

## 读懂筛查

- 缺值按 CSV 必填字段计数，源文件错误在入库前修复。重复时刻、倒序和间隔按原文件筛查。相邻互异 UTC 时刻的间隔小于声明周期的 0.5 倍或大于 3 倍时标记复核。倍数为软件筛查口径，实际允许范围由采集方案确定。
- 重复行比例按额外重复行数除以已校验样本数。采样率观测值取正时间间隔中位数的倒数。缺测率须结合预期样本序列或采集设备记录确认，CSV 的空字段与时间空档分别保留。
- 每路可填写正数 `full_scale_m_s2`，采用声明安装通道适用的对称量程。绝对读数达到或超过该值时记作量程候选。确认饱和需回查硬件状态、记录转换和现场量程。未声明时显示未知。
- 时钟漂移需要独立共同基准和试验时段内的多点同步记录。固定校时、采样间隔偏差和虚构演练都保留“时钟漂移证据不足”。
- 对最大绝对残差 `r`、试验筛查限 `L` 和参考扩展不确定度 `U`，工具检查区间 `[max(0,r−U), r+U]` 是否完全在限内、整体超限，或与界限相交。加速度和时间分别计算。将适用覆盖因子、溯源证书、频段和坐标投影记录在引用的依据中。这里的 `U` 只覆盖参考侧，安装、被测设备、配对和同步等分量请另建不确定度预算。正式判定规则须由试验责任方规定。[JCGM 106 测量不确定度与符合性评价](https://www.bipm.org/en/doi/10.59161/JCGM106-2012)

## 实测验收清单

- [ ] 确认车辆、安装位置、测量方向和完整试验记录，由现场人员签认。
- [ ] 收集参考仪器证书、适用频段、参考轴投影的不确定度和覆盖依据。
- [ ] 采集带共同时间基准的独立原始记录，覆盖试验开始、中段和结束，评估固定偏移、漂移及重复采集的一致性。
- [ ] 按批准的试验方案核对正负激励、多工况重复性、采样与滤波设置及项目允许误差。
- [ ] 归档源文件与参考文件摘要、元数据、传感器版本、逐点证据和报告，由独立人员复算、审阅并记录结论。
- [ ] 若需要工程精度、运行安全或标准符合性结论，按获批标准、测量不确定度预算和判定规则单独验收。

## 参考轴向信号与仿真残差

在「运行分析」的传感器配置区选择当前构架测点，点击「按此测量轴查看仿真响应」。在动力学仿真页展开「参考轴向数据与仿真残差」，下载模板，并记录独立参考值的测量轴、来源编号和相对时间零点。导入 `model_time_s,reference_axis_m_s2` 两列，配置须与当前批次、测点轴向和仿真工况一致。

工具要求至少三个互异的配对时刻，当前投影的输出间隔为 0.01 s。配对采用精确时刻，保留参考 CSV 物理行号和零基模型样本索引。输出包含逐点 `计算值 − 参考值`、RMSE、MAE、绝对峰值误差、Pearson 相关系数、双方摘要、仿真参数、解算器版本及配置版本。常量序列的相关系数显示未定义。逐点记录与汇总可以导出 JSON。更换测点配置或仿真参数后需重新提供配对文件。

练习示例可选一个登记为 +Y 的虚构构架测点，使用 `0,1`、`0.01,1`、`0.02,1` 三行。纯垂向模型在该轴投影为零，三个绝对误差均为 1 m/s²。真实验收还需核验参考轴、时间同步、不确定度、模型适用性与方案规定的误差限。
